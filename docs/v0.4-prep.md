## 1. Executive Summary & Staged Release Plan

The **Subjects2Skills** platform connects conventional Indian school subject curricula (Science, Mathematics, Social Science, Languages, Environmental Studies) with actionable 21st-century cognitive, practical, and social-emotional skills. 

Following the completion of **v0.3**—which established all 13 Grade Profiles (Pre-school through Grade 12), the Grade Navigator (`/grades`), Content Roadmap (`/roadmap`), and the comprehensive Audit & Status system (`/audit-status`)—this blueprint prepares the codebase for **v0.4**. 

To deliver high pedagogy fidelity without regressions, v0.4 is staged into four modular releases:

| Part | Target Milestone | Primary Focus & Deliverables | Primary Route | Scaffolding Status |
| :--- | :--- | :--- | :--- | :--- |
| **Part 1** | **v0.4.1** | **Unit & Lesson Planner**<br>Multi-week thematic unit planning, daily 40-minute lesson step sequences, CBSE competency linkages, printable teacher schedules. | `/planner` | Ready (`/src/data/units.ts`, `UnitCard`, `LessonRow`) |
| **Part 2** | **v0.4.2** | **Skill–Assessment Mapper**<br>Direct skill-to-task correlation, authentic performance tasks, oral inquiry protocols, and 4-tier graduated rubric matrices. | `/assessment-mapper`<br>`/assess` | Ready (`/src/data/assessments.ts`, `AssessmentTaskCard`, `RubricTable`) |
| **Part 3** | **v0.4.3** | **Richer Anchor-Grade Content & Skill Pathways**<br>Detailed exemplar units for anchor grades (3, 6, 9, 11), cross-subject bridges, and longitudinal stage trajectories. | `/pathways` | Ready (`SkillPathwaysPlaceholder`, `GradeProfile` extensions) |
| **Part 4** | **v0.4.4** | **Cross-Grade Search, Filters & Feedback**<br>Multi-attribute taxonomy filtering, keyword search indexing, persistent user feedback collection, and telemetry auditing. | Global Search, Nav & Footer | Ready (`/src/data/feedback.ts`) |

## 2. Data Model & Type System Reference (`/src/types.ts`)

All data structures are strictly typed in TypeScript (`strict: true`, zero `any` declarations) and thoroughly annotated with JSDoc descriptions.

### 2.1 Curriculum Planning Entities

```typescript
export interface Unit {
  id: string;                         // e.g. "g6-sci-u1-water"
  title: string;                      // Thematic title
  gradeId: string;                    // Foreign key to GradeProfile.id
  subjectId: string;                  // Target discipline
  durationWeeks: number;              // Curricular duration (typically 2-4 weeks)
  summary: string;                    // Conceptual overview
  essentialQuestions: string[];       // Inquiry anchors
  learningOutcomes: string[];         // Formal CBSE / NCF outcomes
  skillIds: string[];                 // Connected 21st-century skills
  status: 'draft' | 'published' | 'archived';
  lessons?: Lesson[];                 // Chronological lesson sequence
}

export interface Lesson {
  id: string;                         // Unique lesson identifier
  unitId: string;                     // Parent unit reference
  dayNumber: number;                  // 1-indexed sequential period
  title: string;                      // Descriptive topic
  durationMinutes: number;            // Usually 40 or 80 minutes
  learningObjective: string;          // Specific observable lesson outcome
  steps: LessonStep[];                // Structured instructional phases
  materials: string[];                // Low-cost / classroom resources
  formativeAssessmentHint: string;    // Real-time observation guidance
  skillFocus: string[];               // Primary skill facets targeted
}

export interface LessonStep {
  phase: 'warmup' | 'inquiry' | 'hands-on' | 'reflection' | 'wrapup';
  durationMinutes: number;
  teacherAction: string;
  studentAction: string;
}
```

### 2.2 Assessment & Rubric Matrix Entities

```typescript
export interface AssessmentTask {
  id: string;
  title: string;
  gradeId: string;
  skillId: string;
  subjectId: string;
  taskType: 'performance task' | 'project' | 'question set' | 'investigation';
  durationMinutes: number;
  prompt: string;
  observableEvidence: string[];
  rubricId?: string;
}

export interface AssessmentRubric {
  id: string;
  skillId: string;
  gradeId: string;
  criteria: RubricCriterion[];
}

export interface RubricCriterion {
  id: string;
  name: string;
  weightPercent?: number;
  levels: Record<RubricTier, string>;  // 'emerging' | 'developing' | 'proficient' | 'transfer'
}

export type RubricTier = 'emerging' | 'developing' | 'proficient' | 'transfer';
```

### 2.3 Extended Grade Profile Architecture

The foundational `GradeProfile` interface in `/src/types.ts` was expanded with optional fields to cleanly accommodate enriched anchor grade modules without disrupting existing v0.3 data:

- `sampleUnits?: Unit[]`: Exemplar multi-week thematic curriculum units.
- `sampleProjects?: ProjectExemplar[]`: Interdisciplinary student inquiry capstones.
- `crossSubjectConnections?: CrossSubjectBridge[]`: Cross-department curricular links.
- `bridgeCompetencies?: string[]`: Stage-to-stage developmental transition markers.

### 2.4 Feedback & Telemetry Entities

```typescript
export interface PageFeedback {
  id: string;
  path: string;
  rating: 1 | 2 | 3 | 4 | 5;
  role: 'teacher' | 'parent' | 'admin' | 'student' | 'other';
  feedbackText?: string;
  timestamp: string;
}

export interface UsageEvent {
  id: string;
  eventType: 'route_view' | 'bookmark_add' | 'rubric_inspect' | 'unit_preview';
  targetId?: string;
  timestamp: string;
}
```

## 3. Scaffolding Modules & Reusable UI Components

The following foundational files were created and verified:

### 3.1 Data Scaffolding
- **/src/data/units.ts**: Pre-populated realistic units for Anchor Grade 6 Science (*"Water in Our Lives: Cycles, Conservation & Community Audits"*) and Anchor Grade 3 Mathematics (*"Patterns in Nature: Shapes, Symmetry & Spatial Reasoning"*), populated with multi-step sequenced lessons.
- **/src/data/assessments.ts**: Real-world performance tasks and 4-tier rubric matrices for empirical investigation, proportional reasoning, and collaborative dialogue.
- **/src/data/feedback.ts**: Client-side storage and retrieval layer for teacher ratings, comments, and navigation usage events with graceful localStorage-to-memory fallback.

### 3.2 Modular Component Shells
- **/src/components/UnitCard.tsx**: High-contrast card rendering unit duration, CBSE competencies, status badges, essential questions, and expand/collapse trigger.
- **/src/components/LessonRow.tsx**: Detailed period-by-period instructional row showing structured phases (Warm-up, Inquiry, Hands-on, Reflection), time allocations, resource checklists, and formative assessment cues.
- **/src/components/AssessmentTaskCard.tsx**: Authentic assessment preview card with task type badges, time requirements, observable evidence checklists, and rubric viewer button.
- **/src/components/RubricTable.tsx**: Responsive 4-column matrix mapping performance across *Emerging (Level 1)*, *Developing (Level 2)*, *Proficient (Level 3)*, and *Transfer (Level 4)*.
- **/src/components/SkillRubric.tsx**: Refactored to leverage the unified `RubricTier` type, maintaining complete backward compatibility with v0.3.

## 5. Implementation Playbook for v0.4 Milestones

When prompting subsequent v0.4 releases, developers should follow these implementation blueprints:

### 5.1 Part 1 Implementation Notes (v0.4.1: Unit & Lesson Planner)
1. **Interactive Unit Builder**:
   - Provide an authoring modal or drawer where teachers can choose a Grade (Pre-K to 12) and Subject.
   - Auto-fill suggested CBSE learning outcomes from `/src/data/grades.ts` or `/src/data/subjectMaps.ts`.
2. **Step Sequencing**:
   - Allow teachers to add, delete, or re-order lesson rows.
   - Include a duration tally ensuring the sum of lesson step minutes equals 40 (standard period).
3. **Print & Export**:
   - Integrate print CSS (`@media print`) so lesson cards can be formatted for physical teacher binders.
   - Provide JSON/Text copyable export of lesson plans.

### 5.2 Part 2 Implementation Notes (v0.4.2: Skill–Assessment Mapper)
1. **Interactive Task Filter**:
   - Filter tasks by Grade, Skill Domain (Inquiry, Reasoning, Communication, Emotional), and Task Type.
2. **Student Self-Assessment Mode**:
   - Provide a toggle that translates teacher rubric language into student-friendly "I Can" self-reflection statements.
3. **Evidence Checklist**:
   - Checkboxes allowing teachers to mark observed student evidence during live classroom monitoring.

### 5.3 Part 3 Implementation Notes (v0.4.3: Richer Anchor-Grade Content & Pathways)
1. **Anchor Grades Deep-Dive**:
   - Populate `sampleUnits` and `sampleProjects` for Grades 3 (Preparatory anchor), 6 (Middle anchor), 9 (Secondary entry anchor), and 11 (Higher secondary discipline choice anchor).
2. **Visual Trajectory Graphs**:
   - Utilize lightweight SVG or Tailwind progression trees showing how Grade 3 "Pattern Recognition" directly evolves into Grade 9 "Quadratic Relationships" and Grade 11 "Calculus & Modeling".

### 5.4 Part 4 Implementation Notes (v0.4.4: Search, Filters & Feedback)
1. **Search Indexing**:
   - Build a client-side search index across all 13 grade profiles, 40+ classroom activities, units, and assessment tasks.
2. **Feedback Widget Integration**:
   - Connect the header/footer `open-feedback` event to a lightweight modal that writes to `/src/data/feedback.ts`.
   - Provide an educator summary view in `/admin` displaying aggregated ratings and suggestions.
