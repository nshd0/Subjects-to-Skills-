# Release v0.5.0 — CBSE AI Tracks Fully Integrated

## What's New

Subjects2Skills v0.5.0 brings full CBSE Artificial Intelligence curriculum alignment to life across Grades 3–12.

### Skill Map Visualization
- Color-coded track badges on every skill node:
  - Track A (Compulsory-Embedded): Blue badge
  - Track B (Optional Skill Module): Amber badge
  - Track C (Elective Skill Subject): Emerald badge
- Recommended annual hour allocations displayed per track
- New Track Profile panel in node detail drawers with:
  - Track status and hour breakdowns
  - Curricular transition pathways
  - Verified source citations

### Planning Wizards
- Lesson Plan Wizard now dynamically filters subjects by grade and track:
  - Grades 3–5: Computational Thinking
  - Grades 6–8: Computational Thinking & AI + AI Skill Module 901
  - Grades 9–12: Artificial Intelligence Subject 417
- Assessment Wizard updated to:
  - Present relevant AI and CT subject options per track
  - Align assessment rubrics and focus skills to official CBSE learning outcomes

### Quality & Verification
- Full TypeScript type safety confirmed
- Zero regressions across all grade hubs and planning stages
- Validated via `lint_applet` and `compile_applet`
